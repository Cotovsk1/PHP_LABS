# PHP Labs

Навчальний репозиторій із практичними роботами з **PHP**, HTML, CSS та JavaScript.
Проєкти демонструють базовий синтаксис PHP, роботу з масивами, обробку форм, валідацію даних і взаємодію з браузером через `localStorage`.

## 📚 Практичні роботи

### [Практична робота №1 — Базовий синтаксис PHP](./lab1/)

**Варіант 6: Кулінарна книга**

У роботі реалізовано:

- масив рецептів із назвами, часом приготування, кількістю порцій і складністю;
- список інгредієнтів і категорії рецептів;
- визначення швидких рецептів, якщо час приготування становить не більше 20 хвилин;
- розрахунок середнього часу приготування;
- типізовані PHP-функції та умовну логіку;
- адаптивне оформлення карток рецептів і таблиці результатів.

➡️ [Переглянути README практичної роботи №1](./lab1/README.md)

### [Практична робота №2 — Взаємодія з користувачем](./lab2/)

**Варіант 6: Кулінарна книга**

У роботі реалізовано форму додавання рецепта з підтримкою:

- серверної валідації даних у PHP;
- клієнтської валідації за допомогою JavaScript;
- перевірки назви рецепта, часу приготування та переліку інгредієнтів;
- вибору одиниці вимірювання: грами або унції;
- збереження обраної одиниці вимірювання у `localStorage`;
- безпечного виведення введених даних із захистом від XSS;
- повідомлень про помилки та успішне надсилання форми.

➡️ [Відкрити практичну роботу №2](./lab2/form.php)

## 🛠️ Технології

- **PHP** — серверна обробка та валідація даних;
- **HTML5** — структура вебсторінок і форми;
- **CSS3** — адаптивне оформлення інтерфейсу;
- **JavaScript** — клієнтська валідація та робота з `localStorage`.

## 🚀 Запуск проєкту

### Вимоги

- PHP 8.0 або новіша версія;
- веббраузер із підтримкою JavaScript.

Перевірити встановлену версію PHP можна командою:

```bash
php -v
```

### Запуск через вбудований сервер PHP

У кореневій папці репозиторію виконайте:

```bash
php -S localhost:8000
```

Після цього відкрийте у браузері:

- [Практична робота №1](http://localhost:8000/lab1/)
- [Практична робота №2](http://localhost:8000/lab2/form.php)

Для практичної роботи №1 у Windows також можна скористатися готовим скриптом:

```bat
cd lab1
run_server.bat
```
