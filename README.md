## 🚀 Запуск проєкту

### Вимоги

- PHP 8.0 або новіша версія;
- веббраузер із підтримкою JavaScript.

Перевірити встановлену версію PHP можна командою:

```bash
php -v
```

### Запуск через вбудований сервер PHP

У кореневій папці репозиторію виконайте:

```bash
php -S localhost:8000
```

Після цього відкрийте у браузері:

- [Практична робота №1](http://localhost:8000/lab1/)
- [Практична робота №2](http://localhost:8000/lab2/form.php)

Для практичної роботи №1 у Windows також можна скористатися готовим скриптом:

```bat
cd lab1
run_server.bat
```
