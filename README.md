# PHP Labs

Навчальний репозиторій із практичними роботами з **PHP**, HTML, CSS та JavaScript.
Проєкти охоплюють базовий синтаксис PHP, роботу з формами, ООП, взаємодію з базою даних через PDO та роботу з REST/JSON API.

## Практичні роботи

- [Практична робота №1 — Базовий синтаксис PHP](./lab1/)
- [Практична робота №2 — Взаємодія з користувачем](./lab2/)
- [Практична робота №3 — Основи ООП у PHP](./lab3/)
- [Практична робота №4 — Робота з БД (PDO/MySQL)](./lab4/)
- [Практична робота №5 — AJAX + REST/JSON API](./lab5/)
- [Практична робота №6 — REST API](./lab6/)

## 🚀 Запуск проєкту

### Вимоги

- PHP 8.0 або новіша версія;
- веббраузер із підтримкою JavaScript;
- для `lab4`, `lab5` та `lab6` — MySQL/MariaDB.

Перевірка версії PHP:

```bash
php -v
```

### Запуск через вбудований сервер PHP

У кореневій папці репозиторію виконайте:

```bash
php -S localhost:8000
```

Після цього відкрийте у браузері:

- [Практична робота №1](http://localhost:8000/lab1/)
- [Практична робота №2](http://localhost:8000/lab2/)
- [Практична робота №3](http://localhost:8000/lab3/)
- [Практична робота №4](http://localhost:8000/lab4/)
- [Практична робота №5](http://localhost:8000/lab5/)
- [Практична робота №6](http://localhost:8000/lab6/)

> Для `lab4`, `lab5` та `lab6` за потреби виконайте ініціалізацію БД через `setup.php` у відповідній папці лабораторної.
