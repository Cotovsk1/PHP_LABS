# Практична робота: Знайомство з базовим синтаксисом PHP

## Варіант 6. Кулінарна книга (рецепти, інгредієнти)

### Вимоги варіанта:
- **Дані**: масив рецептів — `title`, `cookTimeMin`, `servings`, `difficulty` (+ `ingredients`, `category`).
- **Умова**: якщо `cookTimeMin <= 20` — мітка «Швидкий рецепт».
- **Агрегат**: середній час приготування по всіх рецептах.

---

### Структура проєкту:
- [`index.php`](./index.php) — головний PHP-скрипт з масивом даних, типізованою функцією, умовною логікою, розрахунком агрегатів та HTML-шаблоном.
- [`style.css`](./style.css) — файл стилів із адаптивною сіткою карток, кольоровими бейджами для міток та таблицею.
- [`run_server.bat`](./run_server.bat) — скрипт для швидкого запуску вбудованого вебсервера PHP (`php -S localhost:8000`).
